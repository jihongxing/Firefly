# Firefly 诊所认证服务 PRD

版本：v2.0  
更新时间：2026-05-27

## 1. 背景

Firefly 定位为宠物医疗版大众点评，核心价值是帮助宠物主找到靠谱的宠物诊所。在这个场景下，诊所面临的核心问题是：

1. **信任问题**：新诊所难以获得用户信任，老诊所需要维护口碑
2. **曝光问题**：优质诊所淹没在海量搜索结果中，难以被发现
3. **转化问题**：用户看到诊所信息后，缺乏足够信息做决策

因此，本项目的首个营收模型定义为：

**诊所认证服务 / Clinic Verification Service**

通过提供官方认证标识、优先展示、数据分析等增值服务，帮助诊所提升可信度和曝光率，同时为平台创造收入。

## 2. 产品目标

### 2.1 商业目标

建立可持续的收入模型，覆盖：

- 服务器与带宽成本
- 图片存储与多媒体处理成本
- 地图产品与社区治理的持续开发
- 基础运营与异常处理成本

**收入预测**：

- 第一年：签约 200 家诊所，年收入 72 万
- 第二年：签约 800 家诊所，年收入 350 万
- 第三年：签约 2000 家诊所，年收入 1000 万

### 2.2 诊所目标

让诊所通过认证服务获得：

- **信任背书**：官方认证标识，提升用户信任
- **优先曝光**：搜索结果优先展示，获得更多流量
- **数据洞察**：了解用户行为，优化服务
- **营销工具**：团购活动、优惠券等营销能力

### 2.3 用户目标

让用户在选择诊所时，能够：

- 快速识别认证诊所，降低决策成本
- 获得更完整的诊所信息（资质、设备、医生等）
- 享受认证诊所提供的优惠活动

## 3. 核心定义

### 3.1 认证诊所

认证诊所是经过平台审核并付费的诊所，具备以下特征：

- **认证标识**：显著的"官方认证"徽章
- **完整信息**：营业执照、医疗许可证、医生资质等
- **优先展示**：搜索结果中排名靠前
- **数据分析**：后台查看曝光、点击、转化数据
- **营销工具**：发布团购、优惠券等活动

### 3.2 认证等级

分为三个等级：

1. **基础认证**：基本信任背书
2. **高级认证**：更多曝光和营销工具
3. **旗舰认证**：最高优先级和全套服务

### 3.3 认证审核

诊所申请认证需提交：

- 营业执照
- 动物诊疗许可证
- 法人身份证
- 诊所实景照片（门头、前台、诊室、设备）
- 医生资质证明（执业兽医师资格证）

审核周期：3-5 个工作日

## 4. 展示规则

### 4.1 搜索结果排序

搜索结果排序规则（权重从高到低）：

1. **认证等级**（40%）
   - 旗舰认证：权重 1.0
   - 高级认证：权重 0.7
   - 基础认证：权重 0.5
   - 未认证：权重 0.3

2. **综合评分**（30%）
   - 评分 4.5+ 分：权重 1.0
   - 评分 4.0-4.5 分：权重 0.8
   - 评分 3.5-4.0 分：权重 0.6
   - 评分 3.5 分以下：权重 0.4

3. **距离**（20%）
   - 1km 内：权重 1.0
   - 1-3km：权重 0.8
   - 3-5km：权重 0.6
   - 5km 以上：权重 0.4

4. **活跃度**（10%）
   - 近 7 天有回复评价：权重 1.0
   - 近 30 天有回复评价：权重 0.7
   - 30 天以上未活跃：权重 0.3

### 4.2 认证标识展示

- **列表页**：诊所名称旁显示认证徽章
- **详情页**：顶部显著位置展示认证信息
- **地图页**：认证诊所使用特殊图标

### 4.3 信息完整度要求

认证诊所必须填写：

- 基本信息：名称、地址、电话、营业时间
- 服务信息：诊疗项目、价格范围、特色服务
- 资质信息：营业执照、医疗许可证、医生资质
- 环境照片：至少 10 张实景照片
- 设备信息：主要医疗设备列表

## 7. 风控与信任边界

### 7.1 必须遵守

1. **真实性原则**：所有认证信息必须真实有效
2. **公平性原则**：认证不影响评价系统的公正性
3. **透明性原则**：用户可查看认证诊所的资质信息
4. **可撤销性原则**：违规诊所立即取消认证

### 7.2 禁止行为

认证诊所不得：

- 刷单刷评价
- 删除或隐藏负面评价
- 冒用他人资质
- 虚假宣传
- 恶意攻击竞品

违规处理：

- 首次违规：警告 + 暂停认证 7 天
- 二次违规：暂停认证 30 天
- 三次违规：永久取消认证 + 退款

### 7.3 审核机制

- **入驻审核**：人工审核资质材料
- **定期复审**：每年复审一次资质
- **用户举报**：用户可举报虚假信息
- **平台抽查**：随机抽查诊所信息真实性

## 8. 数据分析功能

### 8.1 基础数据（基础认证包）

- 曝光量：诊所在搜索结果中的展示次数
- 点击量：用户点击诊所详情页的次数
- 点击率：点击量 / 曝光量
- 导航次数：用户点击"导航"的次数
- 电话拨打次数：用户点击"电话"的次数

### 8.2 高级数据（高级认证包）

- 用户画像：性别、年龄、宠物类型分布
- 转化漏斗：曝光 → 点击 → 导航 → 电话
- 时段分析：不同时段的流量分布
- 来源分析：搜索、地图、推荐等来源占比
- 竞品对比：与同区域诊所的数据对比

### 8.3 旗舰数据（旗舰认证包）

- 竞品分析报告：同区域诊所的详细分析
- 用户行为路径：用户在平台上的完整行为链路
- 流失分析：用户为何没有选择本诊所
- 营销效果分析：团购、优惠券的转化效果

## 12. 定价策略

### 12.1 定价逻辑

参考大众点评、美团等平台的商家认证服务：

- 大众点评：¥3000-10000/年
- 美团：¥5000-15000/年

Firefly 定价策略：

- **低于竞品**：降低诊所入驻门槛
- **按月付费**：降低决策成本
- **年付优惠**：提高用户留存

### 12.2 价格敏感度测试

在 MVP 阶段，测试不同价格的转化率：

- A 组：¥199/月
- B 组：¥299/月
- C 组：¥399/月

根据转化率和收入，选择最优价格。

### 12.3 动态定价

根据城市、竞争情况、诊所规模，动态调整价格：

- 竞争激烈的城市：价格上浮
- 诊所密度低的城市：价格下调
- 大型连锁诊所：定制化报价

## 14. 竞品分析

### 14.1 大众点评

**优势**：

- 品牌知名度高
- 用户基数大
- 商家认证体系成熟

**劣势**：

- 价格高（¥3000-10000/年）
- 宠物医疗不是核心品类
- 信息不够专业

### 14.2 美团

**优势**：

- 流量大
- 团购模式成熟
- 配送能力强

**劣势**：

- 价格高（¥5000-15000/年）
- 宠物医疗占比小
- 评价系统不够垂直

### 14.3 Firefly 差异化

- **价格优势**：¥299/月起，低于竞品
- **垂直优势**：专注宠物医疗，信息更专业
- **信任优势**：资质认证更严格，用户更信任
- **数据优势**：提供宠物医疗专属数据分析

## 15. 风险与应对

### 15.1 风险

1. **诊所付费意愿低**
   - 应对：降低价格，提供试用期

2. **认证诊所作弊**
   - 应对：严格审核，违规取消认证

3. **用户不信任认证标识**
   - 应对：公开认证标准，展示资质信息

4. **竞品降价竞争**
   - 应对：提升服务质量，增加差异化功能

### 15.2 退出机制

如果认证服务效果不佳，可考虑：

- 调整定价策略
- 增加免费试用期
- 转向其他商业模式（如团购佣金）

## 16. 结论

Firefly 的诊所认证服务不是简单的广告位售卖，而是：

**帮助优质诊所获得信任和曝光的增值服务**

这样既能为诊所创造价值，也能为平台创造收入，同时提升用户体验。

核心原则：

1. **真实性**：认证信息必须真实
2. **公平性**：认证不影响评价公正性
3. **价值性**：认证确实能帮诊所获得更多客户
4. **可持续性**：建立长期稳定的商业模式
