# Firefly 产品需求文档

版本：v3.0  
更新时间：2026-05-27

## 1. 产品概述

### 1.1 产品名称

萤火网络 / Firefly

### 1.2 名称寓意

“Firefly（萤火）”强调分布式、微光汇聚的协作精神。平台希望把分散的优质医疗资源、善意和行动连接起来，让养宠人和流浪动物都能获得可负担的医疗服务。

### 1.3 产品定位

**宠物医疗版”大众点评” + 公益救助协作**

一个基于地理位置（LBS）的宠物医疗服务发现平台：

- **核心功能**：帮助养宠人找到附近性价比高的宠物医院/诊所
- **差异化**：真实用户评价 + 价格透明 + 公益属性加持
- **辅助功能**：流浪动物救助协作网络

### 1.4 核心价值

**对养宠人：**
- 发现附近性价比高的宠物医院/诊所
- 查看真实用户评价和价格信息
- 避免被过度医疗和高价收费
- 在线预约，节省时间

**对宠物诊所：**
- 低成本获客渠道
- 展示专业能力和服务质量
- 通过真实口碑建立信任
- 公益友好标签提升品牌形象

**对流浪动物救助者：**
- 快速找到愿意提供救助的诊所
- 发现附近的救助资源和志愿者
- 降低救助成本

### 1.5 产品基调

- 主色调：温暖、可信赖、专业
- 宠物医疗：清晰、透明、高效
- 公益救助：温暖、有爱、行动导向

### 3.2 宠物医疗服务（核心功能）

#### 3.2.1 地图展示

**功能描述：**
- 基于用户位置展示附近的宠物诊所/医院
- 支持筛选：性价比、评分、距离、公益友好
- 地图标记显示关键信息：名称、评分、价格标签

**交互设计：**
- 默认展示3km范围内的诊所
- 点击标记显示诊所卡片预览
- 支持列表/地图视图切换

#### 3.2.2 诊所详情页

**基础信息：**
- 诊所名称、地址、电话
- 营业时间
- 环境照片
- 资质证明（营业执照等）

**价格信息：**
- 常见项目价格（疫苗、绝育、体检等）
- 价格区间显示
- 用户补充的价格信息
- 团购套餐

**评价信息：**
- 综合评分（价格、服务、专业度、环境）
- 用户评价列表
- 评价图片
- 有用/无用投票

**公益标签：**
- 救助友好标识
- 救助案例数
- 救助故事

**操作按钮：**
- 在线预约
- 电话咨询
- 导航
- 收藏

#### 3.2.3 用户评价系统

**评价规则：**
- 必须消费后才能评价（通过预约系统验证）
- 评价维度：价格（5星）、服务（5星）、专业度（5星）、环境（5星）
- 可上传照片（最多9张）
- 可标注具体项目和价格

**评价激励：**
- 高质量评价获得积分
- 积分可兑换优惠券
- 评价被点赞获得额外积分

**评价管理：**
- 评价不可删除（诊所不能删差评）
- 恶意评价可举报
- 社区投票标记可疑评价

#### 3.2.4 在线预约

**预约流程：**
1. 选择诊所
2. 选择服务项目
3. 选择时间
4. 填写宠物信息
5. 确认预约

**预约管理：**
- 查看预约记录
- 取消/改约
- 预约提醒
- 到店核销

#### 3.2.5 团购套餐

**套餐类型：**
- 疫苗套餐
- 体检套餐
- 绝育套餐
- 洗护套餐

**套餐信息：**
- 套餐内容
- 原价/团购价
- 使用规则
- 有效期

### 3.3 救助协作（辅助功能）

#### 3.3.1 救助站点地图

**站点类型：**
- 救助站
- 粮仓
- 公益友好诊所
- 领养中心

**站点信息：**
- 位置、联系方式
- 服务内容
- 开放时间
- 用户评价

#### 3.3.2 求助发布

**发布内容：**
- 位置（模糊坐标）
- 照片
- 描述
- 紧急程度

**发布规则：**
- 支持匿名发布
- 自动推送给附近救助者
- 状态更新（待救助/救助中/已完成）

#### 3.3.3 公益友好标签

**标签规则：**
- 诊所可申请"救助友好"标签
- 需提供救助案例证明
- 标注救助优惠政策
- 展示救助案例数

**标签权益：**
- 搜索结果优先展示
- 公益标签显示
- 用户认同感加分

## 4. 核心场景

### 4.1 养宠人就医场景

**场景描述：**
用户的宠物需要看病/体检/疫苗，希望找到性价比高的诊所。

**用户路径：**
1. 打开地图，查看附近诊所
2. 筛选评分高、价格合理的诊所
3. 查看详情页的价格和评价
4. 在线预约或电话咨询
5. 到店就医
6. 就医后评价

**痛点解决：**
- 不知道附近有哪些诊所 → 地图展示
- 不知道价格是否合理 → 价格透明
- 不知道服务质量如何 → 真实评价
- 预约麻烦 → 在线预约

### 4.2 救助者寻找资源场景

**场景描述：**
救助者发现流浪动物需要医疗救助，希望找到愿意提供优惠的诊所。

**用户路径：**
1. 打开地图，筛选"公益友好"诊所
2. 查看诊所的救助政策和案例
3. 联系诊所确认救助优惠
4. 带流浪动物就医
5. 分享救助故事

**痛点解决：**
- 不知道哪些诊所愿意提供救助优惠 → 公益友好标签
- 救助成本高 → 救助优惠政策
- 缺乏信任 → 救助案例展示

### 4.3 诊所获客场景

**场景描述：**
小型诊所希望获得更多客户，但广告成本高。

**用户路径：**
1. 入驻平台，填写基础信息
2. 上传环境照片、资质证明
3. 设置常见项目价格
4. 申请"公益友好"标签（可选）
5. 接收预约，服务客户
6. 获得真实评价，提升排名

**痛点解决：**
- 获客成本高 → 免费入驻
- 难以建立信任 → 真实评价
- 缺乏差异化 → 公益友好标签

## 6. 页面结构

### 6.1 首页（地图页）

**页面目标：**
让用户快速找到附近的宠物诊所。

**页面结构：**

1. **顶部导航栏**
   - 城市/定位
   - 搜索框（诊所名称、地址）
   - 筛选按钮

2. **地图区域**
   - 诊所标记（显示评分和价格标签）

   - 范围圈（3km/5km/10km）

   - 评分：4.5+/4.0+/3.5+

## 7. 数据模型

### 7.1 核心实体

#### 诊所（Clinic）

```typescript
{
  id: string
  name: string
  address: string
  location: { lat: number, lng: number }
  phone: string
  businessHours: string
  photos: string[]
  license: string // 营业执照
  rating: number // 综合评分
  reviewCount: number
  priceLevel: 'low' | 'medium' | 'high' // 价格档次
  isCharityFriendly: boolean // 公益友好
  charityPolicy: string // 救助政策
  charityCount: number // 救助案例数
  services: string[] // 服务项目
  status: 'active' | 'pending' | 'suspended'
  createdAt: Date
  updatedAt: Date
}
```

#### 评价（Review）

```typescript
{
  id: string
  clinicId: string
  userId: string
  appointmentId: string // 关联预约，验证真实性
  rating: {
    overall: number // 综合评分
    price: number // 价格评分
    service: number // 服务评分
    professional: number // 专业度评分
    environment: number // 环境评分
  }
  content: string
  photos: string[]
  serviceType: string // 服务项目
  price: number // 实际价格
  helpfulCount: number // 有用投票数
  status: 'active' | 'hidden' | 'reported'
  createdAt: Date
}
```

#### 预约（Appointment）

```typescript
{
  id: string
  clinicId: string
  userId: string
  serviceType: string
  appointmentDate: Date
  appointmentTime: string
  petType: 'cat' | 'dog' | 'other'
  petAge: number
  symptoms: string
  contactPhone: string
  status: 'pending' | 'confirmed' | 'completed' | 'cancelled'
  createdAt: Date
}
```

#### 用户（User）

```typescript
{
  id: string
  phone: string
  nickname: string
  avatar: string
  points: number // 积分
  level: number // 等级
  isRescuer: boolean // 是否救助者
  createdAt: Date
}
```

#### 价格信息（PriceInfo）

```typescript
{
  id: string
  clinicId: string
  serviceType: string
  price: number
  priceRange: { min: number, max: number }
  source: 'clinic' | 'user' // 来源
  userId?: string // 用户补充的价格
  createdAt: Date
}
```

#### 救助站点（RescueStation）

```typescript
{
  id: string
  name: string
  type: 'station' | 'food_bank' | 'clinic' | 'adoption'
  location: { lat: number, lng: number }
  address: string
  contact: string
  description: string
  photos: string[]
  status: 'active' | 'inactive'
  createdAt: Date
}
```

### 7.2 关系说明

- 一个诊所可以有多个评价
- 一个用户可以有多个评价和预约
- 一个预约对应一个评价（评价需要预约验证）
- 一个诊所可以有多个价格信息
- 诊所和救助站点是独立的实体（诊所可以申请公益友好标签）

## 8. 商业模式

### 8.1 收入来源

#### 8.1.1 诊所认证服务（主要收入）

**服务内容：**
- 基础认证：营业执照验证、资质审核
- 高级认证：实地考察、专业评估、权威背书
- 公益友好认证：救助案例验证、公益政策审核

**定价策略：**
- 基础认证：免费（前期）→ 299元/年
- 高级认证：999元/年
- 公益友好认证：免费（鼓励公益）

**认证权益：**
- 搜索结果优先展示
- 认证标识显示
- 数据看板权限
- 预约管理功能
- 评价回复权限

#### 8.1.2 团购套餐佣金

**运作模式：**
- 诊所发布团购套餐
- 平台收取10-15%佣金
- 用户在线购买，到店核销

**套餐类型：**
- 疫苗套餐：原价300元，团购价199元
- 体检套餐：原价500元，团购价299元
- 绝育套餐：原价1500元，团购价999元

#### 8.1.3 广告服务

**广告位：**
- 首页推荐位（3个）
- 搜索结果置顶（按点击付费）
- 详情页推荐（相关诊所）

**定价策略：**
- 首页推荐：500元/天
- 搜索置顶：0.5元/点击
- 详情页推荐：200元/天

#### 8.1.4 数据服务（长期）

**服务对象：**
- 宠物保险公司
- 宠物用品品牌
- 行业研究机构

**服务内容：**
- 行业报告
- 用户画像
- 市场趋势

### 8.2 成本结构

**固定成本：**
- 服务器成本：5,000元/月
- 人力成本：50,000元/月（5人团队）
- 办公成本：10,000元/月

**变动成本：**
- 地图API：按调用量计费
- 短信验证码：0.05元/条
- 云存储：按存储量计费
- 支付手续费：0.6%

### 8.3 盈利预测

**第一年：**
- 收入：认证服务30万 + 团购佣金20万 + 广告10万 = 60万
- 成本：固定成本78万 + 变动成本10万 = 88万
