# Firefly 赞助套餐与定价表

版本：v1.0  
更新时间：2026-05-27

## 1. 定价原则

Firefly 的赞助体系遵循以下原则：

1. 公益优先，价格门槛保持友好
2. 按区域和场景售卖，不做全站粗放投放
3. 套餐卖的是“主赞助位曝光份额”
4. 城市系数用于区分不同市场活跃度

## 2. 基础套餐

## 2.1 30% 守护包

- 单片区、单场景
- 主赞助位约 30% 有效地图会话占比
- 扩展赞助位可轮播露出
- 建议价：**¥299 - ¥499 / 月**

适合：

- 单店型猫粮狗粮商家
- 小型友好医院
- 本地救援用品合作商

## 2.2 70% 常驻包

- 单片区、单场景
- 主赞助位约 70% 有效地图会话占比
- 建议价：**¥599 - ¥999 / 月**

适合：

- 本地稳定经营商家
- 有明确流浪动物支持能力的合作门店
- 想长期建立片区存在感的品牌

## 2.3 100% 独占主赞助包

- 单片区、单场景
- 主赞助位 100% 占比
- 适合医院、连锁门店、品牌赞助商
- 建议价：**¥1299 - ¥2999 / 月**

适合：

- 区域宠物医院
- 连锁门店
- 猫粮狗粮品牌赞助计划

## 3. 城市系数

基础套餐价乘以城市系数，形成最终价格带。

| 城市类型 | 系数 | 说明 |
|--------|------|------|
| 小城 / 低活跃市场 | `x1.0` | 起步推广、降低合作门槛 |
| 普通二线 / 高活跃地级市 | `x1.2` | 适合已有一定救助活跃度的区域 |
| 一线 / 核心城区 | `x1.5` | 搜索与协作需求更集中 |

## 4. 场景系数

| 场景 | 系数 | 说明 |
|------|------|------|
| 仅救助协作 | `x1.0` | 常规场景 |
| 仅风险补给 | `x1.1` | 更偏应急，价值略高 |
| 风险 + 救助全场景 | `x1.3` | 同时覆盖两类用户意图 |

## 5. 价格计算方式

最终月费公式建议为：

`基础套餐价 × 城市系数 × 场景系数`

说明：

- 第一阶段可以在报价单中直接写成固定区间，不必向外公开公式
- 运营内部按公式快速生成报价

## 6. 报价示例

## 6.1 小城，救助场景，30% 守护包

- 基础价：¥299 - ¥499
- 城市系数：`x1.0`
- 场景系数：`x1.0`
- 最终建议报价：**¥299 - ¥499 / 月**

## 6.2 普通二线城市，救助场景，70% 常驻包

- 基础价：¥599 - ¥999
- 城市系数：`x1.2`
- 场景系数：`x1.0`
- 最终建议报价：**¥719 - ¥1199 / 月**

## 6.3 一线核心城区，全场景，100% 独占包

- 基础价：¥1299 - ¥2999
- 城市系数：`x1.5`
- 场景系数：`x1.3`
- 最终建议报价：**¥2533 - ¥5848 / 月**

建议对外报价时做顺手取整，例如：

- ¥2599 / 月
- ¥3299 / 月
- ¥4999 / 月

## 7. 售卖单位

建议套餐售卖单位为：

- `城市`
- `5km 片区包`
- `场景`

即一个订单最小单位为：

**某城市某 5km 片区某场景的一档曝光份额**

## 8. 增值项

第一阶段不建议复杂化，但可以预留以下增值项：

1. 多片区联投折扣
2. 连锁门店城市包
3. 品牌公益联名包
4. 节日 / 绝育季 / 救助季专题赞助位

## 9. 续费策略

建议续费规则：

1. 连续续费 3 个月，可赠送一档扩展位加权
2. 连续续费 6 个月，可获一次片区调整机会
3. 首批合作商可给予“公益合作价”标签和首月试投

## 10. 结论

赞助位的价格不追求高单价，而追求：

- 低门槛成交
- 更高续费率
- 更强本地网络效应

这比一开始把价格抬太高更符合 Firefly 的定位。
